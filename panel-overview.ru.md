# Документация по возможностям панели

Этот раздел описывает основные возможности C3 CELERITY для двух аудиторий:

- администраторов, которые работают с веб-панелью;
- интеграторов, которые используют API, подписки, webhooks и MCP.

Документация разбита на несколько файлов, чтобы отделить повседневную работу в панели от интеграций и эксплуатационных операций.

## Что входит в возможности панели

Панель объединяет несколько уровней управления:

- администрирование пользователей, узлов и серверных групп;
- выпуск и обслуживание подписок для клиентских приложений;
- настройку Hysteria 2 и Xray VLESS узлов;
- каскадные топологии и визуализацию сети;
- мониторинг, статистику, логи и SSH-доступ;
- внешние интеграции через API keys, webhooks и MCP;
- резервное копирование, восстановление и обслуживающие операции.

## Карта возможностей

### Базовые сценарии администратора

- первичная настройка панели и создание администратора;
- защита входа через пароль, TOTP и ограничения доступа;
- создание пользователей, управление сроком действия и трафиком;
- объединение узлов в серверные группы;
- создание и обслуживание Hysteria 2 и Xray узлов;
- просмотр конфигураций перед развёртыванием;
- работа со статистикой, логами и состоянием системы.

### Продвинутые сценарии

- автоматическая настройка удалённых узлов по SSH;
- встроенный терминал и broadcast terminal для массовых команд;
- настройка маршрутизации, ACL и клиентского поведения подписок;
- каскадные цепочки с ролями portal, bridge и relay;
- визуальная диагностика topology и статусов на Network Map;
- кастомные конфигурации для узлов и специальные Xray/Hysteria-параметры.

### Внешние сценарии и интеграции

- управление через scoped API keys;
- выдача подписок в разных форматах для клиентских приложений;
- webhook-уведомления о событиях панели;
- доступ AI-ассистентов через MCP tools и prompts;
- сервисные проверки состояния и журналов через API и MCP.

## Как читать этот комплект

Если вы настраиваете панель впервые, начните с [гайда по интерфейсу панели](./panel-user-guide.ru.md), затем перейдите к [гайду по настройкам](./panel-settings.ru.md).

Если вам нужна автоматизация или внешняя интеграция, сразу откройте [интеграции и API](./panel-integrations.ru.md).

Если вы работаете с цепочками узлов, нестандартной маршрутизацией или Xray-спецификой, используйте [продвинутый сетевой гайд](./panel-advanced.ru.md).

## Что важно помнить

- часть операций в Settings изменяет глобальное поведение панели и сразу влияет на всех пользователей;
- backup restore, maintenance reset и custom config override относятся к операциям повышенного риска;
- cascade-сценарии и terminal-доступ требуют предварительной проверки узлов и понимания сетевой схемы;
- API keys, webhook secrets и MCP access нужно рассматривать как чувствительные административные данные.
